# EE黑客松 · 像素开发现场

黑金现场投影页面，固定 1920 × 1080，整页等比缩放，不做手机端重排。

## 实时数据

直接同步问卷系统的只读脱敏接口 https://wenjuan.leftseinem.dpdns.org/api/live-floor ，约每 10 秒获取登记数据。组号、组名、赛道和人数来自当前队伍记录，人数按 members 实际条数汇总，不把组数当人数。每组 Token 通过实际分配的库存 API 关联已有服务端用量缓存，不需再维护另一份组与密钥的对应表。

- 显示各赛道的真实组数、人数，每组累计 Token，全场已知累计 Token。没有报名的赛道整块隐藏、不占位置；第一组报名后，在下一轮同步中自动显示并重新排布。最后一组退出后自动隐藏，不补齐固定数量的空桌。
- 按实际登记组数生成工位，没有每赛道 10 组或全场 50 组的显示上限，不翻页、不隐藏队伍。自动分配赛道宽度、行列与统一工位缩放，全部已登记队伍同时显示；下拉框可选择全部队伍。
- 仅当北京时间 2026-10-18 13:00 已到且后台 apiReleased=true 时展示真实 Token。之前统一为 0，角色休息。不会自动打开问卷发放开关。未分配 API 的组显示 0 并标明未分配。
- 有 API 但尚未查询成功的组显示 —，不能用 0 冒充；失败保留有效缓存并注明待更新，认证失效不继续显示旧数。合计缺少部分组时标记“已知部分”。
- 用量复用问卷 v6 的共享采集器：最多 3 并发，上一轮完成后至少间隔 30 秒；上游记账可能延迟，不是逐请求即时数据。多个大屏和后台共用一轮。
- 查询接口没有实时并发，正式 Token 展示启用后已分配组显示“实时请求状态未知”，不伪造敲码。
- 费用、余额、密钥、个人联系方式、学号、领取码和关键词不出现在大屏数据中。网络断开保留上一份数据并显示“数据待更新”。

累计 Token 是密钥历史累计，包含以前使用；库存回收不会重置上游数据。如果要统计仅本次活动增量，需要单独增加开场/换钥基线。

## 点击查看作品（2026-10-19）

点击小人、头顶队名或选择小组，直接打开黑金作品展示弹窗。左侧显示作品名称、简介、赛道获奖标记和截图，支持切换截图及打开大图；右侧保留六套形象切换和累计 Token。关闭按钮、Esc 或点击遮罩可返回会场；弹窗包含键盘焦点约束。正常轮询不重置当前截图，选中队伍移除时自动关闭。

公开数据在 data/showcase.json，以稳定 teamId 关联问卷队伍；图片在 assets/showcase/，按需加载。当前接入已确认的 42 队作品，其中 40 队有截图，共 55 张；43/47 号尚缺图片，24/31/32/42 号暂未确认作品提交。2026-10-19 用户逐图确认 04/05/06/10/16/20/27（四张）/29/33/34/41，共补入 14 张。Reader 图归 04 号青屿Campus；29 号展示《知行 · 校园通知到行动助手》，41 号展示《留白 · 日程助手》。原 meetingVAR 提交包与旧命名保留在本地历史档案。导入器优先使用本地档案「公开展示确认.json」中的明确映射，避免旧记录覆盖新确认。简介及截图不代表在线试玩或完整运行验收。

补充资料可编辑 JSON 与图片，再按现有 Pages 流程发布。tools/import-showcase.py 为本机归档导入工具，需要 Python Pillow；用 --archive 指定成果概览目录，必要时 --floor-snapshot 指定公开接口快照。脚本核对 ID、队名、赛道，仅导出审核后的简短介绍和截图，不导出报名个人信息、原始包、凭据或内部路径。来源 SHA 和对应记录保存在被忽略的 private-backups/。新增队伍需先补充已核实简介；不要自动导入归属待核材料。

### 形象设置

每个新出现的小组首次随机分配六套像素角色中的一套。点击小人或头顶标签，在详情中的“更换形象”直接点击预览图即可替换，选中项有金色边框；也可点击“换个随机形象”换成另一套。下拉选择小组同样可以更换。

形象按稳定组号保存，自动用量同步、组别排序变化或刷新页面都不会覆盖选择。随机初始形象也会记住。设置只保存在当前浏览器的 localStorage 中，不上传服务器，不跨设备同步；浏览器禁止存储时仍可切换，但只在当前页面有效。存储内容只有组号和形象编号。

## 倒计时与布局

活动结束时间因现场延迟调整为北京时间 2026-10-18 18:00，页面时间为 13:00–18:00。开场前倒数至开场，活动期间倒数至结束，结束后归零；15:00 时剩余 3 小时。最后 10 分钟高亮。配置在 countdown.js，含明确 +08:00 时区；设备时钟须准确。

舞台、标题、讲台、五个开放赛道保留原黑金样式；角色采用原生 PNG 像素帧，关闭图像平滑，队伍较多时统一缩放工位。高清画布按实际显示尺寸与设备像素密度渲染。角色头顶队名与 Token 共用标签和连接线；长队名自动换成两行，仍过长时末尾省略，悬停或点击查看全名，点击查看完整组名和精确 Token。

## 打开与部署

无构建步骤、无前端依赖。GitHub Pages 使用 main 分支根目录，.nojekyll 保留。数据接口只为 https://leftseinem.github.io 设置跨域读取，部署至其他 origin 时需调整服务器白名单；直接 file 打开可显示布局，但真实数据读取受浏览器跨域策略影响。静态文件不包含任何访问凭据。

后端模块位于 ../checkin-system/floor-data.mjs，路由见 server.mjs，部署脚本为 Deploy-Floor.ps1。只新增公开投影，不修改报名记录、库存分配、关键词及发放开关。
